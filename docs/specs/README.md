## Site chrome

### Sticky header

- Sticky at top: 0, 64px tall. After 8px of scroll it gets var(--header-bg), a 12px backdrop blur and a 1px var(--border) bottom line; back at 0px it clears.
- Skip link is the first tab stop and moves focus to <main id="main" tabindex="-1">.
- Theme toggle is a button whose label names the theme it switches to; the choice is saved in localStorage "mimix-theme" and applied before paint by an inline script.

### Mega-menu (1024px and up)

- Opens on hover after 150ms of intent (Radix delayDuration=150, skipDelayDuration=300) and on click or Enter/Space.
- Trigger is a <button aria-expanded aria-controls>; the panel is a list of links grouped with role="group" and aria-label.
- ArrowDown from the trigger enters the panel; ArrowDown/ArrowRight and ArrowUp/ArrowLeft move between links (wrapping); Home/End jump to first/last.
- Esc closes the panel and returns focus to its trigger. Tab past the last link closes it.
- Hidden below 1024px, where the drawer takes over.

### Mobile drawer (below 1024px)

- Below 1024px a menu button opens a right-side dialog (Radix Dialog): role="dialog", aria-modal, labelled by its title.
- Focus moves into the dialog and is trapped; page scroll is locked; Esc, the close button, the overlay or any link closes it and focus returns to the menu button.
- Sections are an accordion of 52px triggers; links are at least 44px tall.

### Footer

- `<footer>` with a labelled `<nav>` of five link columns (Products, Solutions, Developers, Company, Legal), the newsletter form and the copyright line. Background var(--surface), top border 1px var(--border).

## Component behavior reference

### FAQ accordion

- Radix Accordion type="single" collapsible: one panel open at a time; opening another closes the first.
- Each question is a <button aria-expanded aria-controls> inside a heading (h2 or h3 to fit the outline). Enter/Space toggles; ArrowUp/ArrowDown move between questions; Home/End jump.
- Panels animate height in 250ms, instantly under reduced motion.

### Sample player

- Play/pause button: 44×44px, aria-pressed and a label that names the clip ("Play Wren, calm narration").
- Starting any player pauses every other player on the page (shared audio bus).
- The waveform is role="slider" with aria-valuemin/max/now in seconds and aria-valuetext as "0:04 of 0:11". Arrow keys seek 5% of the clip, PageUp/PageDown 20%, Home/End go to start/end; click or drag seeks.
- Load errors are announced through role="alert".

### Billing toggle (segmented control)

- Radix ToggleGroup type="single" (role="radio" items). Arrow keys move, Enter/Space selects; one value is always selected.
- A visually hidden role="status" announces "Showing annual prices, billed yearly" or "Showing monthly prices".

### Live demo

- Textarea with visible label and live character count ("74 of 300 characters") linked by aria-describedby; over 300 characters sets aria-invalid, shows the error and disables Play.
- Voices are a radio group in a fieldset with a legend.
- Play calls POST /api/demo/tts (same-origin check, 20 requests a minute per client) and plays the returned WAV; the button turns into Stop. Errors and rate limits show inline and are announced by role="status".

### Slider

- Radix Slider: role="slider" with aria-valuetext. Blend slider: 0 to 100 in steps of 1; fine-tune sliders: -1 to 1 in steps of 0.05, read as "Higher 40". Arrow keys step, PageUp/PageDown take 10 steps, Home/End go to the ends.

### Triangle blend pad

- Three-voice pad: the handle is role="slider" with aria-valuetext naming all three weights. Arrow keys move it 3% per press (Shift for 10%), Home recentres it; the position is clamped inside the triangle. Pointer drag uses pointer capture.

### Tabs (code sample)

- Radix Tabs: arrow keys move between cURL, JavaScript and Python; the code block is focusable (tabindex="0") and scrolls horizontally. The Copy button confirms with "Copied", or says copying failed, through a polite live region.

### Search and filters

- role="search" form; every select has a visible label. Results count is announced through role="status".
- Filters and search text are mirrored to the URL (?gender=female&q=…) with history.replaceState, so a filtered view can be shared; the empty state offers a reset button.

### Form with inline validation

- noValidate form: fields validate on blur and on submit with the same zod schema the server uses. Errors sit under each field, linked by aria-describedby, with aria-invalid on the field.
- On submit errors, an error summary (role="alert", tabindex="-1") takes focus and links to each field (Contact sales). Newsletter moves focus back to the email field.
- Submitting disables the button and sets aria-busy; success and server errors are announced through role="status".
- Contact sales has a hidden honeypot field; the APIs check same origin, rate limit (newsletter 5 a minute, contact 5 per 10 minutes per client) and validate again.

### Data table

- Real <table> with a visually hidden <caption> and scope="col" headers. When wider than the screen, it scrolls inside a focusable region (tabindex="0", role="region", labelled by the section heading).
- Check and dash cells carry visually hidden text ("Included" / "Not included").

### Breadcrumbs

- <nav aria-label="Breadcrumb"> with an ordered list; the current page has aria-current="page". Mirrored in BreadcrumbList JSON-LD.

### Scroll reveal

- Content is visible by default. When motion is allowed, sections below the fold fade in (opacity 0→1, translateY 16px→0, 400ms var(--ease-enter)) as they enter the viewport. Never armed under prefers-reduced-motion, and always visible when printed.

## Breakpoints and layout

- Mobile first. Tailwind breakpoints: sm 640px, md 768px, lg 1024px (desktop nav), xl 1280px, 2xl 1536px.
- `.container-content`: max-width 1200px; side gutter 16px, 24px from 640px, 32px from 1024px. `.container-wide`: max-width 1440px.
- Header height 64px. Touch targets at least 44×44px. Body text 16px/26px Figtree; display Sora; code JetBrains Mono.
